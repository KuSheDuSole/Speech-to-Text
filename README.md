# Speech-to-Text с диаризацией
 
Система автоматического распознавания речи с разделением по спикерам.  
Поддерживает **Windows**, **Linux (Ubuntu)** и **macOS**. 

Версии проекта с их установщиками под каждую ОС вынесены в отдельные одноименные 
ветки. В каждой ветке есть инструкция по установке и эксплуатации
 
---
 
## Системные требования
 
| | Windows | Linux (Ubuntu) | macOS |
|---|---|---|---|
| Python | 3.11.x | 3.11.x | 3.11.x |
| GPU | NVIDIA (опц.) | NVIDIA (опц.) | Apple Silicon MPS (опц.) |
| Место на диске | ~10 GB | ~10 GB | ~10 GB |
 
> **Важно:** только Python 3.11.x — другие версии не поддерживаются.

### Меню программы
 
```
1 — Записать аудио
2 — Обработать последнее записанное аудио
3 — Выбрать файл вручную и обработать
4 — Управление hotwords      [текущее кол-во]
5 — Настройки спикеров       [авто / 1-4 чел.]
0 — Выход
```
 
**Hotwords** — слова которые модель будет распознавать приоритетно  
(аббревиатуры, имена, термины). Лимит: 25 слов. Регистр не важен.
 
**Настройки спикеров** — можно зафиксировать число говорящих  
или оставить автоопределение.
